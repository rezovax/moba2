Ядро - матачи, карта, логика персонайже, бои, итп - rust.
игровой сервер - rust, udp, мат
остальной backend - просто аккаунты, авторизация, разлчиный стейт для менюшики итп, typescript + prisma db.

Текущая архитекутра предолагает:

GameWorld/ИгровойМир/GW - системообразующая ядро, фундаментальная зависимость проект. Реализует правила игры, инварианты, персонажи, крипы, применение способностей, единицы измерения, тики, время, масштаб карты итп, команды Язык - rust. Зависимости - ядро не завист ни от чего, от ядро завият остальные. Нарушение этой границы неприемлимо. Строгие тесты.

Match - абасркация над матчем, еще до конца не обдумано.

Симулятор - использует(зависит от) GW, Матч чтобы подкючить ботов и проводить тестирования. Основная задача - машинное обучение ботов и настройки баланса на основе. Поддеркжа тысяч одноверменных матчей.

Игровой Сервер -> горизонтально масштабируемый backend, использующий GM, Match для создания матчей уже реальных игровок, с аккаунтами авторизауциец, сетевым протоколом для работыс godot клиентом

Клиент - godot + rust extenstion для GameWorld.
