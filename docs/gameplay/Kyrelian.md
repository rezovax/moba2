Священник — Отлучённый
1–3 — Ауры. Каждая кнопка включает/выключает соответствующую ауру.
Одновременно могут работать несколько аур.
1 → эффект A
2 → эффект B
3 → эффект C
1 + 2 → появляется новый эффект AB
1 + 3 → AC
2 + 3 → BC
1 + 2 + 3 → ABC
Таким образом у игрока всего четыре кнопки, но фактически 7 состояний персонажа + ультимейт.

Священник фармит через ауру
Например Аура Суда (3) воздействует и на миньонов.
Миньоны внутри нее постепенно получают урон, но не обычный DPS. На них копится Осуждение:
○ → ◔ → ◑ → ◕ → ●
Когда шкала заполняется — происходит небольшой импульс урона.
Так игрок может управлять фармом позиционированием.
