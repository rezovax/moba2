# moba2

Новая MOBA-игра на Godot 4. Репозиторий рассчитан на совместную разработку
клиента и сервера; сейчас активен только клиент.

## Структура

- `client/` — Godot-проект игры.
- `client/scenes/` — сцены, сгруппированные по игровым областям.
- `client/scripts/` — GDScript-код с той же структурой, что и сцены.
- `client/assets/` — исходные игровые ресурсы по типам.
- `client/tests/` — автоматические тесты клиента.
- `tools/` — воспроизводимые команды разработки и CI.

## Быстрый старт

```bash
godot --editor --path client
```

Проверка качества:

```bash
./tools/check.sh
```

Проект использует полностью статически типизированный GDScript. Все встроенные
предупреждения Godot 4.7 повышены до ошибок, а `gdlint` и `gdformat --check`
запускаются через закреплённое Python-окружение `uv`.

Quality gate также запрещает подавление предупреждений и незавершённые
заглушки, а цикломатическая сложность каждой функции ограничена значением 5
(только категория A).
